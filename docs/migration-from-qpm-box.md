# 从 qpm-box 迁移

`qpm-thoughtline` 是从早期 `qpm-box`/“青萍助手·念头”实现整理出的独立 Web 项目。迁移分为代码目录迁移和用户数据迁移两部分。

## 代码目录

当前源码仓库不包含浏览器构建产物、工具状态或增量构建文件；使用 `npm ci` 即可重新安装 Web 依赖。

## 浏览器数据

如果新版本运行在与旧版本相同的浏览器 origin 下，它会在首次读取时寻找旧 key：

- `qpm-box-graph-v1`
- `qpm-box-last-export`
- `qp-theme`

数据会复制到 `qpm-thoughtline-*` 命名空间。首次启动后请打开设置页确认任务和念头仍在，并立即导出一份新 JSON 备份。

如果部署域名或端口改变，浏览器 origin 也会改变，自动迁移无法跨 origin 工作。此时请在旧版本设置页导出 JSON，再在新版本选择“导入备份”。

## JSON 备份

旧 `qpm-box-graph` 备份仍可导入。导入时会按 ID 合并，较新的任务/节点覆盖本地数据，边按 ID 去重。新版本导出的格式已经改为 `qpm-thoughtline-graph`。

## 旧桌面数据

当前 Web 版不读取 SQLite 数据库，也不会自动扫描桌面应用数据目录。需要迁移旧桌面数据时：

1. 在旧桌面版本打开应用。
2. 在设置页导出完整 JSON 备份。
3. 打开 Web 版，在设置页导入 JSON。
4. 检查任务、节点、边和处理状态，并再次导出备份。

确认迁移完成前，请保留旧 SQLite 文件和 JSON 备份；不要直接复制数据库文件到浏览器存储。

## 不兼容的内容

- 不支持直接导入旧 SQLite 文件；请使用旧版本导出的 JSON。
- 不保证旧版本缓存的构建产物可直接复用。
