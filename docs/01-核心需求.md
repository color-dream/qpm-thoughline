## 1. 产品定位

**青萍助手是一套面向「人机协作过程」的轻量工具集。**

「青萍」取自浮萍之意：轻、随水而生、易被忽略。产品意在捕捉协作间隙里那些容易漂走、容易被丢掉的念头与上下文，并把它们重新系回正在进行的工作。

它不替代 AI 执行工具，也不替代通用笔记软件。它的位置在两者之间——**人把活交给 AI 之后、到人与 AI 再次对齐之前的那段协作间隙。**

### 1.1 产品形态

- 青萍助手是一个**工具集（Toolkit）**，由若干可独立使用的小工具组成。
- 各小工具围绕同一主题：**降低人机协作中的认知摩擦与信息流失**。
- 首个小工具（下文详述）聚焦「等待期的想法记录与上下文衔接」。
- 后续小工具在同一产品框架下扩展，共享统一的入口、身份与数据基础。

## 2. 时代背景与问题

### 2.1 工作方式的变化

AI 时代，人们把越来越多的执行类工作交给 AI：写代码、写文档、做调研、生成素材、跑分析。人与 AI 的关系从「人用工具」逐渐变成「人与智能体协同完成任务」。

### 2.2 新出现的协作断裂

这种协同带来一个被普遍低估的问题：**AI 执行任务往往需要一段时间，而这段等待会打断人的连续思维。**

具体表现为两类信息流失：

| 类型 | 场景 | 后果 |
| --- | --- | --- |
| **等待中冒出的新想法** | AI 在跑，人去干别的事或单纯发散思考；此时对当前任务冒出补充/调整念头，或冒出完全无关的新 idea | 想法一闪而过，没有低摩擦的记录入口，事后想不起来 |
| **回来后的上下文断裂** | 人离开较久后回来，面对 AI 的产出/进度 | 很难接上「派任务之前自己在想什么」，协作衔接不畅，需要重新进入状态，效率与质量都受损 |

### 2.3 现有方案为什么不够

| 现有方案 | 缺口 |
| --- | --- |
| 通用笔记软件（备忘录、Notion 等） | 与 AI 任务上下文脱钩；记下来也是孤岛，难以「续上」协作 |
| AI 会话历史 / 长对话 | 记录的是与 AI 的交互，不是人自己的念头与决策链 |
| 待办清单 | 只能记「要做什么」，不能还原「当时怎么想的」 |
| 纯聊天窗口备忘 | 随对话滚动淹没，无法串联、无法回溯 |

**结论：市场缺少一个专门服务「人机协作间隙」的思维记录与衔接工具。**

## 3. 目标用户

### 3.1 主要用户

把执行工作大量交给 AI，并需要在此期间保持思考与决策质量的知识工作者。典型画像：

- 工程师 / 技术负责人：让 AI 写代码、重构、跑测试，自己在旁设计、审查、想方案
- 产品 / 设计 / 运营：让 AI 调研、写稿、出方案，自己补充创意与约束
- 独立创作者 / 研究者：多任务并行，AI 常驻后台，人跨任务切换

### 3.2 用户特征

- 多线程：AI 在跑任务时，人很少干等着
- 重视上下文：回来后希望能「续上」而不是「重来」
- 想法密度高：等待期产出的念头有价值，但往往零散、易失

## 4. 首个小工具：「念头」

> 暂定名「念头」。正式命名可在产品阶段再定。

「念头」是青萍助手工具集中的第一个落地工具，直接对应上述问题。

### 4.1 一句话定义

**在 AI 干活的等待间隙里，低摩擦地记下你的想法，并在你回来时帮你接上思路、推进协作。**

### 4.2 核心能力

围绕「记 → 串 → 续」三步：

| 能力 | 说明 |
| --- | --- |
| **记（Capture）** | 极低摩擦地记录一闪而过的想法；支持语音、快捷键、随手输入 |
| **串（Link）** | 将想法与「正在等的 AI 任务」绑定；将任务前的想法、等待中的补充、任务后的反思串成一条时间/因果链 |
| **续（Resume）** | 人回来时，自动呈现该任务相关的想法链与决策上下文，帮助快速进入状态，并可直接把新想法喂给 AI 继续协作 |

### 4.3 关键使用场景

#### 场景 A：任务进行中冒出对当前任务的新想法

1. 用户把「重构登录模块」交给 AI 执行
2. 等待期间，用户突然想到「还要兼容第三方 OAuth」
3. 用户快速记录该想法，并关联到「重构登录模块」任务
4. AI 任务完成后，青萍助手提示：你还有 1 条关联想法
5. 用户确认后，想法被纳入下一步，与 AI 协作继续推进

#### 场景 B：等待期冒出无关新 idea

1. AI 在跑调研报告，用户去处理别的事
2. 途中冒出「下个季度要不要做播客」的念头
3. 用户随手记下，标记为独立想法（不绑定当前任务）
4. 事后可在想法池中回看、归类、择机转成任务

#### 场景 C：很久回来，无法衔接之前的思路

1. 用户上午派了任务，下午才回来
2. 打开青萍助手，看到该任务的「思维续接卡」：
   - 派任务时的目标与约束（任务前想法）
   - 等待中补充的想法（时间线）
   - AI 当前进度 / 产出摘要
3. 用户 30 秒内恢复上下文，决定「接受 / 调整 / 追加」，与 AI 继续协作

#### 场景 D：事后复盘一条任务的完整思路

1. 任务结束后，用户可回看整条时间线：目标 → 中途想法 → AI 产出 → 最终决策
2. 可导出或沉淀为个人工作记录

### 4.4 功能需求（MVP）

#### P0（必须有）

| 编号 | 功能 | 描述 |
| --- | --- | --- |
| F-01 | 快速记录 | 全局快捷键唤起极简输入框，支持文本；可选语音输入 |
| F-02 | 任务关联 | 记录时可选择关联到某个「进行中的 AI 任务」，也可作为独立想法 |
| F-03 | 任务上下文卡 | 每个关联任务有一页：目标、时间线（想法流）、当前状态 |
| F-04 | 回来提示 | 用户再次打开 / 回到该任务时，展示「续接摘要」：时间线 + 待处理想法 |
| F-05 | 喂给 AI | 支持将选中的想法整理后，直接作为补充指令发送给 AI 协作方 |

#### P1（应尽快有）

| 编号 | 功能 | 描述 |
| --- | --- | --- |
| F-06 | 语音转写 | 语音想法自动转文字，保留原始音频 |
| F-07 | 想法池 | 未关联任务的想法汇总视图，支持标签、搜索、简单整理 |
| F-08 | 时间线串联 | 自动按任务串联「任务前 → 等待中 → 任务后」的完整链路 |
| F-09 | 多 AI 适配 | 可对接不同 AI 工具（对话助手、编码 Agent 等）的任务状态 |

#### P2（后续增强）

| 编号 | 功能 | 描述 |
| --- | --- | --- |
| F-10 | 智能聚类 | 自动把相似/相关想法聚在一起，提示潜在主题 |
| F-11 | 跨任务关联 | 识别某任务的想法是否也适用于其他任务 |
| F-12 | 导出与沉淀 | 导出为 Markdown / 结构化记录，便于长期复盘 |
| F-13 | 团队协作 | 多人共享任务思维链（需额外隐私与权限设计） |

### 4.5 非功能需求

| 维度 | 要求 |
| --- | --- |
| **摩擦** | 记录一条想法 ≤ 3 秒（唤起 + 输入 + 关联/跳过） |
| **轻量** | 常驻/唤起方式极轻，不打断当前工作流 |
| **隐私** | 想法默认本地优先；同步需用户显式开启 |
| **可续性** | 任意时刻断开后，能从任务卡完整恢复上下文 |
| **可扩展** | 作为工具集一部分，为后续小工具预留统一数据与交互底座 |

### 4.6 成功指标（建议）

| 指标 | 说明 |
| --- | --- |
| 记录留存率 | 等待期产生想法后实际记录的比例 |
| 回来续接时间 | 从打开任务到「进入状态、做出下一步决策」的平均时长 |
| 想法→行动转化 | 关联想法最终被采纳/喂给 AI/转为任务的比例 |
| 次日回访 | 用户次日仍使用该工具的比例 |

## 5. 工具集扩展方向（占位）

青萍助手定位为工具集。「念头」是第一个。后续可围绕人机协作链路继续展开，例如（仅作方向参考，未立项）：

- **交办卡**：把任务目标、约束、验收标准结构化，更清晰地派给 AI
- **验收镜**：AI 产出后，对照检查「是否还符合我当初的想法」
- **碎片池**：与具体任务无关的灵感长期收纳与定期整理

新工具需与「念头」共享同一协作上下文，避免成为新的信息孤岛。

---

## 6. 明确的边界（Non-goals）

青萍助手 **不做**：

- 不做通用 AI 对话/执行引擎（对接现有 AI 工具）
- 不做通用笔记/知识库（专注协作间隙的思维衔接）
- 不做任务管理套件（Todo、甘特、OKR 等）
- MVP 阶段不做重度社交/社区功能

## 7. 风险与待决策

| 风险 / 待决策 | 说明 |
| --- | --- |
| 与 AI 工具的对接方式 | 各家 AI 产品接口/形态差异大，MVP 如何低成本接入？ |
| 记录入口的形态 | 全局快捷键？悬浮球？系统托盘？与 OS 集成程度？ |
| 「任务」的定义 | 用户如何创建/识别一个「AI 任务」？自动检测还是手动登记？ |
| 命名与品牌 | 「念头」是否合适；主品牌「青萍助手」的视觉与语气 |
| 平台优先级 | 桌面端（Windows/macOS）优先，还是移动端，或两者？ |

---

## 8. 总结

**青萍助手**定位为服务人机协作过程的轻量工具集。第一个小工具 **「念头」** 要解决的是：

> AI 在干活时，人的想法容易丢、思路容易断——青萍帮你记下、串起，并在你回来时接上。

产品抓住的是 AI 时代新出现、尚未被现有工具覆盖的协作间隙，切入点小而准，具备清晰的用户价值与可扩展的产品框架。
