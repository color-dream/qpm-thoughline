## 0. 计划原则

1. **先跑通黄金路径**：热键 → 记想法 → 画布见节点 → 回来能续 → 剪贴板交给 AI。
2. **画布是一等公民**：不做「列表优先、画布后补」。
3. **严格 MVP 边界**：语音、AI 自动感知、云同步、扩展/MCP 全部后置。
4. **每周可演示**：每个里程碑结束必须有可点可玩的构建物，而不是只写文档。
5. **本地优先、可回滚**：数据与布局都能导出；破坏性迁移要有备份策略。

## 1. 范围总览

### 1.1 本期做（MVP，M0–M3）

| 能力 | 说明 |
| --- | --- |
| 捕获层 | 全局热键，文本快速记录，默认挂最近任务 |
| 任务 | 创建 / 列表 / 状态（running / waiting_review / done） |
| 思维链画布 | 平移、缩放、拖节点、连边（child/related）、框选、双击新建、任务 fit |
| 节点类型 | task / thought / ai / free |
| 想法池 | free 节点列表 + 画布定位 |
| 交给 AI | 选中节点 → 结构化文本 → 剪贴板 |
| 通知 | 任务完成且有未消化想法 → 系统通知 → 聚焦画布 |
| 存储 | SQLite 本地；节点坐标与边持久化 |
| 主题 | 明（纸感）/ 暗（infinite-canvas zinc） |
| 打包 | Windows x64 安装包或便携 exe |

### 1.2 本期不做

- 语音转写
- 自动监听第三方 AI 内部进度
- 云同步 / 账号
- 浏览器扩展 / MCP / 本地 HTTP API
- 团队协作
- 智能聚类、自动美化布局（仅「放射整理」）
- 多画布项目切换
- macOS 打包（代码预留跨平台，不作为出口标准）

## 2. 技术基线（冻结）

| 层 | 选型 | 备注 |
| --- | --- | --- |
| 壳 | Tauri 2 | Windows 优先 |
| 前端 | React 18 + TypeScript + Vite | |
| 状态 | Zustand | canvas / tasks / settings 分 slice |
| 画布 | 自研 DOM 节点 + SVG 边 | 不用 React Flow（MVP） |
| DB | SQLite（tauri-plugin-sql 或 rusqlite） | |
| 样式 | CSS Variables + 明暗 token | 对齐 design/画布交互稿.html |
| 测试 | Vitest（逻辑）+ 手测清单（画布手势） | Playwright 可选后补 |

### 2.1 仓库结构（目标）

```
qpm-box/
  docs/
  design/
  src/                     # React
    overlay/               # 捕获层
    app/                   # 主壳：侧栏 + 画布
    features/
      canvas/              # 相机、节点、边、手势、布局、小地图
      tasks/
      thoughts/
      settings/
    shared/                # types, ipc, theme
  src-tauri/               # Rust
    src/
      main.rs
      shortcut.rs
      tray.rs
      notify.rs
      capture_window.rs
      db/
      clipboard.rs
  package.json
  tauri.conf.json
```

### 2.2 数据模型（落地表）

```sql
tasks(id TEXT PK, title TEXT, goal TEXT, status TEXT, source TEXT, created_at, updated_at, meta TEXT)
nodes(id TEXT PK, kind TEXT, ref_id TEXT, x REAL, y REAL, width REAL, height REAL, collapsed INTEGER, created_at, updated_at)
thoughts(id TEXT PK, task_id TEXT NULL, content_text TEXT, kind TEXT, origin TEXT, created_at, updated_at, meta TEXT)
edges(id TEXT PK, source_id TEXT, target_id TEXT, kind TEXT, created_at)
events(id TEXT PK, task_id TEXT, type TEXT, payload TEXT, created_at)  -- 可选，M3 再定
```

写路径约定：`thoughts.task_id` 与 `edges(kind=child)` 同步维护；画布以 edges 为准，列表以 task_id 为准。

## 3. 迭代节奏建议

| 迭代 | 周期建议 | 里程碑 | 主题 |
| --- | --- | --- | --- |
| 迭代 0 | 3–5 天 | **M0 骨架** | 能呼出、能关掉 |

## 4. 里程碑详拆

### M0 · 骨架（迭代 0）

**目标**：Tauri 应用可启动，托盘与捕获层热键通路打通。

| # | 任务 | 出口 |
| --- | --- | --- |
| M0-1 | 初始化 Tauri 2 + React-TS 工程于 `qpm-box` | `pnpm tauri dev` 可跑 |
| M0-2 | 单实例锁 + 窗口基础配置 | 双开被拒或聚焦已有实例 |
| M0-3 | 系统托盘图标与菜单（记想法 / 打开 / 退出） | 托盘可操作 |
| M0-4 | 全局热键 `Ctrl+Shift+Space` | 热键唤起捕获小窗 |
| M0-5 | 捕获层 UI（空提交即可）Enter/Esc | 键盘通路 |
| M0-6 | 设计 token 接入（明暗变量） | 切换主题壳变色 |
| M0-7 | CI 本地脚本：`dev` / `build` / `typecheck` | README 可复制命令 |

**M0 出口标准**：热键必现捕获窗，Enter 有 Toast 反馈（可不落库），Esc 关闭；托盘可退出。

**不做**：DB、画布、完整设置。

---

### M1 · 画布 + 存储（迭代 1）

**目标**：想法落库并出现在画布上，能拖、能连、能缩放平移。

#### M1-A 数据层

| # | 任务 | 出口 |
| --- | --- | --- |
| M1-1 | SQLite schema + migration | 启动自动建表 |
| M1-2 | CRUD：task / node / thought / edge | 单元测试覆盖主路径 |
| M1-3 | 种子数据或「新建任务」最小 UI | 非空画布可测 |
| M1-4 | 捕获保存：写 thought + node + child 边 | 重启后仍在 |

#### M1-B 画布引擎

| # | 任务 | 出口 |
| --- | --- | --- |
| M1-5 | 相机：pan / wheel zoom（光标锚点） | 手感对齐交互稿 |
| M1-6 | 节点渲染：task/thought/ai/free | 视觉对齐 token |
| M1-7 | 边渲染：child 实线 / related 虚线 | |
| M1-8 | 拖节点（含多选拖动） | 坐标写回 DB（防抖） |
| M1-9 | 端口连边 + 预览线；task 侧自动 child | |
| M1-10 | 框选、点选、Shift 多选、Delete | |
| M1-11 | 双击空白新建 free 节点 | |
| M1-12 | 任务列表侧栏；点击 fit 子树 | |
| M1-13 | 「放射整理」布局 | 一键重排可撤销（至少内存级 undo 可 P2） |

**M1 出口标准**：

1. 热键记一条「重构登录」相关想法 → 画布出现节点并连到 task。
2. 可拖到任意位置，重启后位置仍在。
3. 从 thought 端口拖到另一 thought 出现 related 边。
4. 滚轮缩放、空白拖拽平移流畅（目标 60fps，节点 &lt; 200）。

**风险闸门**：若手势冲突或性能不达标，优先修相机与命中测试，不扩功能。

---

### M2 · 续接闭环（迭代 2）

**目标**：人离开再回来，能恢复上下文并把想法交给 AI。

| # | 任务 | 出口 |
| --- | --- | --- |
| M2-1 | 「交给 AI」选中集合 → 固定中文模板 → 复制 | 剪贴板有正确全文 |
| M2-2 | 未选中时默认取 focus task 的 pending 想法 | |
| M2-3 | 任务状态标记 running / waiting_review / done | |
| M2-4 | done 且有未消化 thought → Windows 通知 | 点击通知打开并 fit 任务 |
| M2-5 | 想法池面板：free 列表 + 在画布定位 | |
| M2-6 | 任务节点角标：未读/pending 数量 | |
| M2-7 | 贴回 AI 产出：粘贴/手输生成 ai 节点 | |
| M2-8 | 折叠/展开任务子树 | 画布可收纳 |
| M2-9 | 小地图 + 当前视口框 | 点击/拖动可导航（点击即可） |

**M2 出口标准（流程 B）**：

1. 记 2 条等待中想法 → 标记任务完成 → 出现通知。
2. 点通知 → 画布 fit 该任务 → 一键「交给 AI」。
3. 到任意外部窗口 Ctrl+V 可见结构化文本。

| 项 | 预算 |
| --- | --- |

## 7. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 画布手势与系统/IME 冲突 | 主路径受阻 | M1 尽早真机验证；保留键盘路径 |
| Windows 透明捕获窗兼容 | 唤起失败 | 降级为不透明深色窗 |
| 范围膨胀（想做重白板） | 延期 | 非目标写入 PR 检查；新需求进 P1 池 |
| SQLite 写并发/损坏 | 数据丢失 | 单写队列；启动 integrity；导出备份 |
| 热键被占用 | 用不了 | 设置可改 + 托盘入口 |
| 设计 token 与实现漂移 | 视觉走样 | 以 `design/画布交互稿.html` 为视觉基线，PR 截图对比 |
