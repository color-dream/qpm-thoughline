## 已知限制（web-first 形态）

- 全局热键、托盘、系统级唤起在浏览器不可用；页面聚焦时 Ctrl+Shift+Space 可用
- 系统通知依赖浏览器授权；后台标签页收不到应用内 toast
- localStorage 约 5MB 且可能被浏览器清理——设置页有用量显示，请定期「导出 JSON」备份
- SQLite migration v2 的历史数据重建是有损的（v1 bug 已把同任务想法覆盖为一条，无法凭空恢复）
- 桌面壳恢复时，`npm run tauri:dev` 起应用即自动跑 migration，无需手动操作
